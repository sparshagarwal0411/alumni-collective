# Alumni Collective

Build a premium, minimalist college alumni networking platform using React 19, Vite, TypeScript, Tailwind CSS v4 and Supabase, following the provided architecture.md and flow.md. The design must feel human-designed, sophisticated and editorial, inspired by premium university websites and modern design portfolios, with warm off-white backgrounds, charcoal text, elegant typography, generous whitespace, thin dividers, subtle accents and intentional asymmetrical layouts. Strictly avoid generic AI-generated SaaS aesthetics: no excessive rounded cards, repetitive card grids, purple-blue gradients, glassmorphism, neon glows, floating blobs, unnecessary shadows or overused animations. Use open layouts, clean lists, timelines, typography-led sections and varied compositions instead of putting everything inside boxes. Implement a searchable alumni directory, detailed profiles, mentorship and messaging, an interactive alumni relationship graph, jobs and internships, referrals, microtasks, alumni analytics, a dedicated donation page with contribution amounts, fundraising goals, impact stories and secure payment integration, plus a newsletter subscription and community updates section. Include authentication, role-based access, responsive mobile layouts, accessible components and proper loading, error and empty states. Reuse the existing architecture, connect real functionality through Supabase, implement database security and never expose API keys or fake successful transactions. Use realistic sample data only where necessary and clearly distinguish it from real data. Prioritize excellent visual consistency, usability and working core features over flashy effects. The final product should look like a carefully art-directed university alumni platform built by a professional design team, not a template generated by AI. Inspect the existing codebase first and implement changes without breaking working functionality.
